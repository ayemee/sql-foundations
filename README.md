# SQL Foundations

This repository documents my hands-on learning journey through SQL fundamentals.

The goal is to build a strong understanding of relational databases and query writing through structured phases, exercises, and practical examples.

---

## Learning Goals

- Understand relational database concepts
- Write SQL queries confidently
- Learn how applications interact with databases
- Build backend data intuition as a frontend engineer
